# 👋 Welcome to meanmail.dev

We build **developer tools** and **productivity plugins** for JetBrains IDEs, helping developers work more efficiently.

## 🚀 Featured Projects

### IntelliJ IDEA Plugins

#### [nginx-intellij-plugin](https://github.com/meanmail-dev/nginx-intellij-plugin) ⭐ 66
Smart support for Nginx configuration files in IntelliJ IDEA. Features syntax highlighting, code completion, navigation, and validation.

#### [PyAnnotations](https://github.com/meanmail-dev/PyAnnotations) ⭐ 7
Code inspections for Python in JetBrains IDEs. Helps maintain code quality with advanced Python-specific checks.

#### [prettify-python-plugin](https://github.com/meanmail-dev/prettify-python-plugin) ⭐ 4
Python code formatting and beautification plugin for IntelliJ-based IDEs.

#### [python-typing-intellij-plugin](https://github.com/meanmail-dev/python-typing-intellij-plugin)
Enhanced Python type hints and annotations support for PyCharm and IntelliJ IDEA.

### Development Tools
