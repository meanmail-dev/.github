# meanmail.dev

We build practical developer tools for JetBrains IDEs.

Our plugins help developers work with Nginx, Python, Ansible, Docker, GitHub Actions, Django,
databases, file formats, and AI-assisted workflows without constantly switching tools. We focus on
IDE-native workflows that make complex work easier to understand and verify: navigation,
inspections, validation, visual tooling, and reliable project context.

[Explore all plugins](https://plugins.jetbrains.com/vendor/meanmail) ·
[Read guides and documentation](https://meanmail.dev) ·
[Get support](https://github.com/meanmail-dev/Bug-Tracker)

## Open-source projects

- [Nginx Configuration](https://github.com/meanmail-dev/nginx-intellij-plugin) — editing support for
  Nginx configuration files in JetBrains IDEs, including highlighting, completion, navigation,
  validation, and structure view.
- [PyAnnotations](https://github.com/meanmail-dev/PyAnnotations) — inspections and quick fixes for
  Python type annotations.
- [IntelliJ Plugin Template](https://github.com/meanmail-dev/intellij-plugin-template) — a starting
  point for IntelliJ Platform plugin projects with Kotlin and CI/CD.
